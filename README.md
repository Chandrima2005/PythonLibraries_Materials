# Python Libraries for Data Science

**Stage 2 of the [Gradient Atlas](https://gradient-atlas.chandrima-das.com) data science pathway:**
Python → **Python libraries** → Machine learning → Deep learning → Generative AI

13 Jupyter notebooks that take you from your first NumPy array to a complete data analysis project with **NumPy, pandas, Matplotlib, Seaborn and SciPy**. Every chapter explains the idea in plain words first, then shows it in small runnable cells, and ends with a common-mistakes table, a cheat sheet and exercises with solutions.

Start with [`00_index.ipynb`](00_index.ipynb).

## The dataset

The examples share one realistic, fully synthetic dataset: a year of sales at **Brew & Byte**, a fictional chain of four coffee shops. It is generated by [`tools/make_data.py`](tools/make_data.py) with a fixed seed, so it is identical on every machine and free to reuse. The files are in [`data/`](data/).

## Run it yourself

```bash
git clone https://github.com/Chandrima2005/PythonLibraries_Materials.git
cd PythonLibraries_Materials
python -m venv .venv
# Windows: .venv\Scripts\activate    macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
jupyter lab
```

Open the notebooks from the repository root so that `data/...` paths resolve.

## How the notebooks are made

The chapters are written in Markdown in [`src/`](src/) and converted to notebooks, then executed so they are committed with their outputs:

```bash
python tools/make_data.py          # regenerate data/ (optional; it is committed)
python tools/build_notebooks.py    # rebuild and execute every chapter
python tools/build_notebooks.py 07 # only Chapter 7
```

To change a chapter, edit `src/NN_*.md` and rebuild; don't edit the `.ipynb` by hand. The style rules are in [`CLAUDE.md`](CLAUDE.md).

## Requirements

Python 3.11+, NumPy 2, pandas 3, Matplotlib 3, Seaborn 0.13+, SciPy 1.x.
